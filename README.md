One-line joke about crypto and trading life for make.fun's "Laugh Track: The Crypto Trading Joke Contest" ($2 in USDC).

`main.py` (Python 3.13, stdlib only) writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt`).

> My diamond hands aren't about conviction — I just forgot my exchange password in 2021, so now I'm legally a long-term investor.
